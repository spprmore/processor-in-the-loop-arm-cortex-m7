System Requirements

REQ-001
The controller shall maintain wheel slip between 0.1 and 0.3 during emergency braking.

REQ-002
The controller shall prevent wheel lock during braking.

REQ-003
The controller shall operate with a fixed sample time of 1 ms.

REQ-004
The model shall support Embedded Coder code generation.

REQ-005
The generated code shall execute on an Arm Cortex-M7 Fast Model using Processor-in-the-Loop (PIL) testing.

REQ-006
MIL and PIL results shall be compared and documented.

REQ-007
The project results shall be published in a GitHub repository together with documentation and test results.
